# SF Compute Provider

Manage [SF Compute](https://sfcompute.com) workspaces, pools, firewalls,
instance templates, InfiniBand partitions, instances and orders, and read
accounts, limits, SKUs, images, pools, orders and instances.

The resources and data sources are generated from SF Compute's OpenAPI
document, so their arguments and attributes follow the
[API reference](https://docs.sfcompute.com/api-reference/pools/list-pools)
one to one. Routes under `/preview/v2` are in SF Compute's public preview and
may change.

## Authentication

Create an API token with `sf tokens create` (or in the dashboard) and grant
it a role, for example `sf grants create --token my-token --role admin
--workspace my-workspace`. Pass it as `token` or in the `SFC_TOKEN`
environment variable; it is sent as `Authorization: Bearer <token>`.

## Spending guard

Some resources cost money as soon as they are created:

* `sfcompute_order` places a buy or sell order on the market.
* `sfcompute_instance` runs on, and draws down, a pool's purchased allocation.

The provider refuses to plan or create these unless it is configured with
`allow_spending = true`. The default is `false`, and there is deliberately no
environment variable for it, so enabling spending is always visible in
configuration. Destroying such resources (cancelling an order, terminating
and deleting an instance) is always allowed.

## Workspaces

Most resources live in a workspace, given as an ID (`wksp_...`) or resource
path (`sfc:workspace:<account>:<workspace>`). Set `workspace` in the provider
block to use a default; resources and data sources that take a `workspace`
use it when theirs is unset.

## Example Usage

```terraform
terraform {
  required_providers {
    sfcompute = {
      source = "hofvarpnir-studios/sfcompute"
    }
  }
}

# The token is read from SFC_TOKEN when not set here. Create one with
# `sf tokens create` and grant it a role with `sf grants create`.
provider "sfcompute" {
  workspace = "sfc:workspace:acme:default"

  # Resources that spend money (sfcompute_order, sfcompute_instance) cannot
  # be created unless this is set. Leave it unset (false) for configurations
  # that should only manage free resources.
  # allow_spending = true
}
```

## Schema

### Optional

- `allow_spending` (Boolean) Allow creating resources that spend money or consume purchased compute (`sfcompute_order`, `sfcompute_instance`). Defaults to `false`, in which case planning such a resource fails with an error. There is deliberately no environment variable for this setting.
- `base_url` (String) API base URL. Defaults to the `SFC_BASE_URL` environment variable, or `https://api.sfcompute.com`.
- `token` (String, Sensitive) SF Compute API token (`sk_live_...`), sent as `Authorization: Bearer <token>`. Create one with `sf tokens create` or in the dashboard, then grant it a role with `sf grants create`. Defaults to the `SFC_TOKEN` environment variable.
- `workspace` (String) Default workspace, as an ID (`wksp_...`) or resource path (`sfc:workspace:<account>:<workspace>`). Used by resources and data sources that take a `workspace` and leave it unset. Defaults to the `SFC_WORKSPACE` environment variable. Changing it does not move existing resources.
